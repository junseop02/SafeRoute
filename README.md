# SafeRoute — AI 기반 초보 운전자 친화 경로 추천 서비스

## 1. 프로젝트 소개

SafeRoute는 초보 운전자와 고령 운전자 등 복잡한 도로 환경에서 운전에 부담을 느끼는 사용자를 위한 AI 기반 경로 추천 서비스입니다.

일반적인 최단 거리 및 최소 시간 중심의 경로 안내와 달리, 도로 특성과 과거 사고다발지역 정보, 차로 수, 교차로 밀집도 등을 활용하여 상대적으로 운전 부담을 줄이는 방향으로 경로를 추천하는 것을 목표로 합니다.

카카오모빌리티 API에서 자동차 경로 후보를 조회하고, 전국 표준 도로망과 매칭하여 사전에 계산된 LightGBM 모델 점수를 활용합니다.

사용자가 설정한 우회 허용 범위 안에서 경로별 추천 점수를 계산하고 비교 결과를 제공합니다.

본 서비스의 추천 점수는 실제 사고 확률이나 운전자의 체감 난이도를 직접 측정한 값이 아니며, 경로의 안전을 보장하지 않습니다.

## 2. 주요 기능

### 2.1 장소 검색 및 자동차 경로 탐색

- 카카오 장소 검색 API를 이용한 출발지 및 목적지 검색
- 카카오모빌리티 자동차 길찾기 API 연동
- 여러 경로 후보 탐색 및 중복 경로 제거
- 카카오 지도를 이용한 경로 시각화
- 경로별 이동 거리 및 예상 소요 시간 표시

### 2.2 AI 기반 도로 분석

- 전국 표준 도로 링크 1,562,356개 활용
- LightGBM 이진분류 모델 기반 사고다발지역 포함 여부 점수 산출
- 전국 도로 데이터를 1,172개의 공간 타일로 구성
- 경로 좌표와 전국 도로 링크의 공간적 매칭
- 매칭된 도로 길이를 가중치로 활용한 경로별 특성 집계

### 2.3 사용자 맞춤 경로 추천

- 최단 후보 경로 대비 우회 허용 범위 설정
- 우회 허용 범위: 1.5배, 2배, 3배, 제한 없음
- 도로 매칭률 80% 이상인 유효 경로 비교
- 서로 다른 비교 가능 경로 최소 2개 확보 시 AI 추천
- 가능하면 비교 가능 경로 3개 이상 탐색
- 경로 추천 점수 및 도로 특성 비교
- 비교 결과 JSON 저장

## 3. 시스템 구성

SafeRoute는 Python 기반 오프라인 모델 학습 환경과 Node.js 기반 실시간 웹 서비스로 구성됩니다.

### 3.1 오프라인 데이터 처리 및 모델 학습

1. 전국 표준 노드·링크 및 사고다발지역 데이터를 수집합니다.
2. 도로 구조 특성을 생성하고 사고다발지역과 도로 링크를 공간적으로 매칭합니다.
3. 사고다발지역 포함 여부를 학습 레이블로 생성합니다.
4. 공간적 데이터 누출을 줄이기 위해 학습·검증·시험 데이터를 분리합니다.
5. LightGBM 모델을 학습하고 성능을 평가합니다.
6. 최종 모델을 이용해 전국 도로 링크별 점수를 산출합니다.
7. 도로 좌표와 모델 점수를 공간 타일로 변환합니다.

### 3.2 실시간 서비스 처리 과정

1. 사용자가 출발지와 목적지를 검색합니다.
2. 카카오모빌리티 API에서 자동차 경로 후보를 조회합니다.
3. 중복 경로를 제거하고 우회 허용 범위를 적용합니다.
4. 경로 주변의 공간 타일을 불러옵니다.
5. 경로 좌표와 전국 도로 링크를 매칭합니다.
6. 도로 링크별 모델 점수와 도로 구조 특성을 집계합니다.
7. P01-v1.1 추천 정책을 적용하여 경로 추천 점수를 계산합니다.
8. 추천 조건을 충족하는 경로를 비교하여 결과를 표시합니다.

실시간 서비스에서는 사전에 계산된 도로 링크 점수를 활용하므로 경로를 검색할 때마다 Python 모델을 실행하지 않습니다.

## 5. AI 모델 및 추천 정책

### 5.1 최종 AI 모델

| 항목 | 내용 |
|---|---|
| 모델 ID | T09 |
| 알고리즘 | LightGBM Binary Classifier |
| 학습 단위 | 도로 링크 |
| 학습 목표 | 과거 사고다발지역 포함 여부 분류 |
| 입력 특성 | 7개 |
| 최종 학습 데이터 | 1,123,804개 |
| 독립 시험 데이터 | 234,353개 |
| 최종 트리 수 | 269개 |
| 모델 출력 범위 | 0~1 |
| 전국 점수 산출 대상 | 1,562,356개 도로 링크 |

학습 레이블은 다음과 같이 정의합니다.

- 1: 제공된 사고다발지역 폴리곤과 양의 길이로 중첩되는 도로 링크
- 0: 제공된 사고다발지역 폴리곤과 양의 길이로 중첩되지 않는 도로 링크

레이블 0은 사고가 발생하지 않았거나 안전한 도로임을 의미하지 않습니다.

### 5.2 모델 입력 특성

| Feature | 설명 |
|---|---|
| `lanes` | 도로 차로 수 |
| `max_spd` | 도로 제한속도 |
| `road_rank` | 도로 등급 |
| `length` | 표준 도로 링크 길이 |
| `n_branch` | 현재 링크의 도착 노드(T_NODE)에서 출발하는 도로 링크 수 |
| `n_intersect_200m` | 링크 대표점 주변 200m 교차로 후보 수 |
| `intersection_nodes_200m` | 링크 전체 주변 200m의 NODE_TYPE 101 노드 수 |

사고다발지역과의 거리 및 사고 건수 등 학습 레이블과 직접 관련된 사고 특성은 모델 입력에서 제외했습니다.

### 5.3 모델 성능

독립 공간 시험 데이터에 대한 평가 결과입니다.

| 평가 지표 | 교차로 수 기반 Baseline | T09 LightGBM |
|---|---:|---:|
| Average Precision | 0.2682 | 0.3865 |
| ROC-AUC | 0.7843 | 0.8445 |
| Accuracy | 0.6494 | 0.8005 |
| Precision | 0.2615 | 0.3591 |
| Recall | 0.9001 | 0.6409 |
| F1-score | 0.4053 | 0.4603 |
| Balanced Accuracy | 0.7556 | 0.7329 |

T09 모델의 Average Precision은 Baseline 대비 약 44.11% 상대적으로 향상되었습니다.

다만 Recall과 Balanced Accuracy는 Baseline보다 낮으므로 모든 평가 지표에서 개선된 것은 아닙니다.

해당 성능은 과거 사고다발지역 포함 여부에 대한 분류 성능이며, 실제 사고 발생 확률이나 초보 운전자의 체감 난이도에 대한 예측 정확도를 의미하지 않습니다.

### 5.4 경로 추천 정책 — P01-v1.1

| 구성 요소 | 가중치 |
|---|---:|
| T09 모델 점수 | 80% |
| 좁은 도로 부담 | 10% |
| 교차로 부담 | 10% |
| 합계 | 100% |

경로별 모델 점수와 도로 특성은 매칭된 도로 길이를 기준으로 집계합니다.

- R: 도로 링크별 T09 모델 점수의 길이 가중평균
- W: 2차로 이상 도로의 매칭 길이 비율
- C: 주변 200m NODE_TYPE 101 노드 수의 길이 가중평균
- B: 최종 경로 부담 점수

경로 부담 점수 계산식:

    B = 0.8 × R + 0.1 × (1 − W) + 0.1 × clip(C / 100, 0, 1)

사용자에게 표시되는 경로 추천 점수:

    Recommendation Score = 100 × (1 − B)

경로 추천 점수는 0~100점이며, 높을수록 현재 추천 정책에서 우선하는 경로입니다.

가중치는 모델이 학습한 값이 아닌 경로 추천 정책의 설정값입니다.

### 5.5 도로 링크 매칭

- 경로 좌표 샘플링 간격: 최대 25m
- 도로 링크 최대 매칭 거리: 18m
- 최소 유효 도로 매칭률: 80%
- 공간 타일 크기: 0.1도
- 전국 공간 타일 수: 1,172개

도로 매칭률이 80% 미만인 경로는 추천 점수를 제공하지 않으며 AI 추천 대상에서 제외합니다.

### 5.6 최종 추천 조건

- 사용자 설정 우회 허용 범위 충족
- 도로 매칭률 80% 이상
- 유효한 모델 점수 존재
- 서로 다른 비교 가능 경로 최소 2개 확보

추천 우선순위는 다음과 같습니다.

1. 경로 부담 점수가 낮은 경로
2. 이동 거리가 짧은 경로
3. 예상 소요 시간이 짧은 경로
4. 경로 ID 순서

예상 소요 시간은 추천 점수 계산에 직접 사용하지 않습니다.

## 7. 설치 및 실행

### 7.1 서비스 실행 환경

- Windows
- Node.js 실행 환경
- 전국 도로 공간 타일 및 매니페스트
- 카카오 REST API 키
- 카카오 JavaScript 키
- 인터넷 연결

신규 서비스 실행에는 Python 가상환경이나 LightGBM 패키지 설치가 필요하지 않습니다.

### 7.2 서비스 실행 방법

1. 프로젝트 루트의 `START_SAFEROUTE.cmd`를 더블클릭합니다.
2. 웹 브라우저에서 SafeRoute 화면이 열립니다.
3. 카카오 REST API 키와 JavaScript 키를 웹 화면에 입력합니다.
4. 지도 연결 후 출발지와 목적지를 검색합니다.
5. 우회 허용 범위를 설정하고 경로를 탐색합니다.
6. 경로 추천 점수와 AI 추천 결과를 확인합니다.

기본 접속 주소:

    http://127.0.0.1:8090

CMD 창은 서비스 이용 중 유지해야 합니다.

### 7.3 API 키 관리

- REST API 키: 장소 검색 및 자동차 경로 탐색
- JavaScript 키: 카카오 지도 표시

카카오 개발자 설정에서 필요한 API 사용 권한 및 웹 서비스 도메인 등록을 확인해야 합니다.

API 키를 소스코드에 직접 작성하거나 GitHub에 업로드하지 않습니다.

### 7.4 모델 개발 및 재학습 환경

모델 학습과 데이터 전처리를 수행할 경우 Python 3.12 환경이 필요합니다.

기존 개발 환경 설정 스크립트:

    SETUP_SAFEROUTE.cmd

Python 패키지 설치:

    python -m pip install -r requirements.txt

신규 전국 모델의 전체 재현에 필요한 추가 의존성과 버전은 최종 환경 점검 단계에서 확정합니다.

### 7.5 팀원 공유 및 배포

전체 개발 프로젝트와 서비스 실행용 배포 패키지를 구분하여 관리합니다.

서비스 실행용 패키지에는 웹 서비스 코드, 전국 공간 타일, 매니페스트, 추천 정책 설정, Node.js 실행 환경 및 실행 파일이 필요합니다.

독립 실행형 배포 패키지 제작과 별도 환경에서의 실행 검증은 최종 배포 단계에서 수행합니다.

## 10. 한계 및 향후 개선

### 10.1 모델·데이터 및 서비스의 한계

- 모델은 과거 사고다발지역 포함 여부를 학습합니다.
- 모델 출력값은 보정된 실제 사고 발생 확률이 아닙니다.
- 사고다발지역 미포함 도로가 안전한 도로임을 의미하지 않습니다.
- 사고다발지역 데이터는 보행노인, 보행어린이, 자전거 및 스쿨존 어린이 관련 유형으로 제한됩니다.
- 사고 데이터와 표준 도로망의 수집 시점에 차이가 있습니다.
- 초보 운전자의 실제 주행 난이도에 대한 직접적인 학습 레이블이 없습니다.
- 경로 추천 정책의 가중치는 학습된 값이 아닙니다.
- 전국 서비스 지원 범위와 모든 지역에서의 모델 성능 보장은 구분해야 합니다.
- 경로 정책의 정량적 비교 실험은 천안·아산 수집 경로를 중심으로 수행했습니다.
- 장소 검색 요청에는 이전 응답이 최신 검색 결과를 덮어쓰는 상황을 방지하는 별도의 요청 식별자 검증이 적용되어 있지 않습니다.
- 지도 범례의 출발지·도착지 색상과 실제 지도 마커 색상이 일치하지 않을 수 있습니다.
- 추가 경로 탐색은 우회 범위 내 경로 후보 수를 기준으로 종료하므로, 도로 매칭률 검증 이후 유효 후보가 부족해질 수 있습니다.
- 자동화 UI 테스트는 모의 DOM 및 지도 SDK 환경을 기반으로 수행하였으며, 모든 실제 브라우저 환경의 정상 작동을 보장하지 않습니다.
