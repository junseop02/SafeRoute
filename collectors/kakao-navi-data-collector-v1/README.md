# 카카오내비 데이터 수집기

카카오 지도에서 출발지와 도착지를 고른 뒤 카카오모빌리티 자동차 길찾기 데이터를 파일로 저장하는 독립 실행 도구입니다. SafeRoute 위험도 샘플이나 LightGBM 모델은 포함하지 않습니다.

## 실행

1. 압축을 풉니다.
2. `START_카카오내비_수집기.cmd`를 더블클릭합니다.
3. 검은 창에 카카오 **REST API 키**를 붙여넣고 Enter를 누릅니다. 키는 화면에 표시되거나 파일에 저장되지 않습니다.
4. 브라우저에서 카카오 **JavaScript 키**를 입력합니다.
5. 출발지와 도착지를 검색해 선택하고 **서로 다른 카카오 경로 찾기**를 누릅니다.

카카오 디벨로퍼스의 JavaScript SDK 도메인에는 `http://localhost:8080`을 등록해야 합니다. 카카오맵과 카카오모빌리티 길찾기 제품도 앱에서 활성화되어 있어야 합니다. 실행 중에는 검은 창을 닫지 마세요.

## 수집 조건

한 번 실행할 때 다음 7개 API 요청을 보냅니다.

- 추천 경로와 추천 대안
- 빠른 경로
- 최단 경로
- 큰길 우선
- 고속도로 제외
- 유료도로 제외
- 스쿨존 제외

카카오가 같은 도로 좌표를 반환한 결과는 자동으로 제거합니다. 그래서 최종 파일의 경로 수는 7개보다 적거나, 추천 대안 때문에 많을 수 있습니다. 가까운 거리나 대체 도로가 없는 구간에서는 한 경로만 남을 수도 있습니다.

## 자동 저장 파일

경로를 수집할 때마다 시간별 파일과 `latest-*` 최신 파일을 함께 만듭니다.

- `data/raw/latest-kakao-routes.json`: 카카오 원본 응답
- `data/processed/latest-routes.json`: 중복 제거 통합 데이터
- `data/processed/latest-routes.geojson`: 경로 도로 구간 좌표
- `data/processed/latest-route-summary.csv`: 거리, 시간, 택시요금, 통행료
- `data/processed/latest-road-segments.csv`: 도로명, 거리, 시간, 교통속도, 교통상태

CSV는 Excel에서 한글이 깨지지 않도록 UTF-8 BOM으로 저장합니다. 카카오 경로 데이터는 선택한 출발지와 도착지 사이의 응답이므로 전체 도로망 데이터나 LightGBM 학습 데이터는 아닙니다.

경로 수집 버튼을 한 번 누를 때 API 요청 7건이 사용됩니다.
