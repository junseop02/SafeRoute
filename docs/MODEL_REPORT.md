## 1. 모델 개발 개요

### 1.1 프로젝트 목적

SafeRoute는 초보 운전자 및 운전에 어려움을 느끼는 사용자를 대상으로 도로 구조와 사고 관련 정보를 고려한 경로 추천 서비스를 제공하는 프로젝트이다.

기존 내비게이션의 최단 거리 및 최소 시간 중심 경로 탐색과 달리 도로 링크별 특성과 과거 사고다발지역 정보를 활용하여 상대적인 경로 추천 우선순위를 제공한다.

### 1.2 기존 모델의 한계

기존 LightGBM 회귀 모델은 도로 특성과 사고 관련 특성을 이용하여 사람이 사전에 정의한 규칙 기반 부담 점수를 학습하였다.

기존 모델의 높은 결정계수와 낮은 예측 오차는 사전에 정의된 점수 계산 규칙을 정확하게 재현하였음을 의미한다.

그러나 해당 성능만으로 실제 사고 위험이나 초보 운전자의 체감 난이도를 정확하게 예측한다고 판단할 수 없다.

이에 따라 신규 모델에서는 실제 수집된 과거 사고다발지역 정보를 학습 레이블로 사용하도록 모델 구조를 변경하였다.

### 1.3 신규 모델 개발 목표

- 실제 수집된 사고다발지역 정보 기반 학습
- 전국 표준 도로망에 대한 도로 링크 단위 분석
- 사고 관련 입력 특성으로 인한 데이터 누수 방지
- 공간 기반 데이터 분할을 통한 평가 신뢰성 확보
- 기준 모델과 신규 모델의 정량적 성능 비교
- 전국 도로 링크 모델 점수 생성
- 실시간 경로 추천 서비스와의 연동

### 1.4 기존 모델과 신규 모델 비교

| 항목 | 기존 모델 | 신규 모델 |
|---|---|---|
| 알고리즘 | LightGBM 회귀 | LightGBM 이진분류 |
| 학습 목표 | 규칙 기반 부담 점수 | 과거 사고다발지역 포함 여부 |
| 학습 범위 | 천안·아산 중심 | 전국 |
| 사고 기반 입력 특성 | 사용 | 제외 |
| 모델 출력 | 규칙 기반 점수 | 사고다발지역 포함 관련 점수 |
| 평가 지표 | R², MAE 등 | AP, ROC-AUC, F1-score 등 |
| 경로 추천 | 기존 부담 점수 기반 | P01 복합 추천 정책 |

기존 회귀 모델과 신규 이진분류 모델은 학습 목표와 평가 지표가 다르므로 두 모델의 성능 수치를 직접 비교하지 않는다.

두 교차로 관련 특성은 노드 선정 기준과 거리 계산 기준이 서로 다르다.

- 사고다발지역 중첩 비율
- 학습 레이블에서 직접 파생된 특성

## 10. 경로 추천 정책 개발 및 서비스 적용

### 10.1 경로 단위 모델 점수 집계

실제 카카오 API에서 수집한 경로 후보와 표준 도로 링크를 매칭하였다.

| 항목 | 결과 |
|---|---:|
| 전체 수집 경로 | 6,402 |
| 매칭률 80% 이상 경로 | 6,303 |
| 전체 출발지·도착지 조합 | 3,076 |
| 복수 경로가 존재하는 조합 | 2,464 |

매칭된 경로 구간의 길이를 가중치로 사용하여 모델 점수를 집계한다.

    R = Σ(length_i × hotspot_score_i) / Σ(length_i)

매칭되지 않은 구간에 임의의 0점 또는 안전 점수를 부여하지 않는다.

### 10.2 추천 정책 구성

신규 모델 점수만으로 경로를 추천할 경우 SafeRoute의 큰길 우선 및 복잡한 도로 회피 목적과 상충할 수 있다.

따라서 모델 점수와 별도의 도로 구조 부담 요소를 결합한 추천 정책을 구성하였다.

주요 구성 요소:

- 사고다발지역 포함 관련 모델 점수
- 좁은 도로 부담
- 교차로 부담

공통 우회 허용 배율 2배 조건에서 791개 출발지·도착지 조합을 비교하였다.

    = -1.354%p

P01 정책은 평균 모델 점수를 감소시켰으나 평균 큰길 비율 감소와 평균 이동 거리 증가가 발생하였다.

이는 모델 점수와 도로 편의성 및 우회 비용 사이의 상충 관계를 보여준다.

### 10.6 최종 P01 추천 점수 계산

경로 모델 점수:

    R = 길이 가중 평균 T09 모델 점수

좁은 도로 부담:

    N = 1 - W

W는 매칭된 경로 중 차로 수 2개 이상 도로의 길이 비율이다.

교차로 부담:

    I = clip(C / 100, 0, 1)

C는 매칭된 도로 링크의 intersection_nodes_200m 특성에 대한 길이 가중 평균이다.

최종 경로 부담 점수:

    B = 0.8 × R + 0.1 × N + 0.1 × I

백엔드 제공 점수:

    model_score = 100 × B

사용자 표시 점수:

    Display Score = 100 - model_score

사용자 표시 점수가 높을수록 현재 정책에 따른 상대적인 추천 우선순위가 높다.

## 12. 연구 제한사항 및 결론

### 12.1 데이터 제한사항

- 사고다발지역 자료는 전체 교통사고 유형을 포함하지 않는다.
- 사고다발지역 데이터는 2012~2024년의 과거 정보를 포함한다.
- 도로망 데이터와 사고 데이터의 수집 시점에 차이가 있다.
- 도로 구조의 과거 변경 이력을 완전하게 반영하지 못한다.
- 사고다발지역 미포함 도로가 안전한 도로라는 의미는 아니다.
- 사고다발지역 폴리곤의 공식 좌표계 명세는 별도 확인이 필요하다.
- 교통량 및 실제 도로 폭 등 일부 도로 특성을 최종 모델에 포함하지 않았다.

### 12.2 모델 제한사항

- 모델은 과거 사고다발지역 포함 여부를 학습한다.
- 모델 출력값은 보정된 실제 사고 발생 확률이 아니다.
- 초보 운전자의 실제 체감 난이도에 대한 직접적인 학습 레이블이 없다.
- 실제 미래 사고 발생에 대한 예측 성능을 검증하지 않았다.
- 모든 미관측 지역의 모델 일반화 성능을 보장하지 않는다.
- 기준 모델보다 Recall 및 Balanced Accuracy가 낮게 나타났다.
- 특성 중요도는 사고 발생의 인과관계를 의미하지 않는다.

- 모델 점수와 큰길 우선 정책 사이에 상충 관계가 존재한다.
- 정책 비교 실험은 천안·아산 수집 경로를 중심으로 수행하였다.
- 실제 추천 경로의 사고 감소 효과는 검증하지 않았다.

신규 및 기존 서비스의 전체 통합 회귀 테스트 213개와 최종 파일 무결성 검사 1,197개를 모두 통과하였다.

현재 개발 환경에서 신규 모델과 추천 정책의 서비스 통합 및 검증을 완료하였다.

다만 신규 모델은 실제 사고 발생 확률이나 초보 운전자의 실제 체감 난이도를 직접 예측하는 모델이 아니며, 향후 실제 사용자 평가와 추가 데이터 확보를 통한 개선이 필요하다.

기존 모델 및 개발 자료는 보존하며 독립 실행형 배포 환경 검증과 팀 인터페이스 변경 승인 이후 최종 공유 및 제출 상태를 확정한다.
