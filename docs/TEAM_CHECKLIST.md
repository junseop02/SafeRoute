## 4. 최종 추천 정책 확인

### 4.1 P01-v1.1 추천 정책

경로 부담 점수는 다음 요소를 결합하여 계산한다.

| 구성 요소 | 가중치 |
|---|---:|
| T09 모델 점수 | 80% |
| 좁은 도로 부담 | 10% |
| 교차로 부담 | 10% |

- R: 매칭된 도로 링크의 길이 가중 평균 모델 점수
- W: 매칭된 경로 중 차로 수 2개 이상 도로의 길이 비율
- C: 매칭된 도로 링크의 길이 가중 평균 교차로 노드 수

경로 부담 점수 B:

    B = 0.8 × R + 0.1 × (1 - W) + 0.1 × clip(C / 100, 0, 1)

사용자 표시 점수:

    Display Score = 100 × (1 - B)

표시 점수가 높을수록 현재 추천 정책에 따른 상대적인 경로 추천 우선순위가 높다.

### 4.2 추천 조건

| 항목 | 적용 기준 |
|---|---|
| 최소 도로 매칭률 | 80% |
| 최소 유효 경로 후보 | 2개 |
| 추가 경로 탐색 목표 | 3개 |
| 우회 허용 배율 | 1.5배, 2배, 3배, 제한 없음 |
| 기본 화면 선택값 | 2배 |
| 우회 배율 기준 | 전체 후보 중 최단 거리 |
| 추천 우선순위 | 부담 점수, 거리, 시간, 경로 ID |
| 매칭률 부족 | 점수 미제공 |
| 유효 경로 부족 | 추천 보류 |

P01-v1.0의 최소 유효 후보 조건은 3개였으나 P01-v1.1에서는 2개로 변경하였다.

해당 변경 과정에서 모델 재학습 및 독립 시험 데이터 재평가는 수행하지 않았다.

## 5. 서비스 실행 환경 및 사용 방법

### 5.1 현재 검증된 실행 환경

| 항목 | 환경 |
|---|---|
| 운영체제 | Windows |
| 포함된 Node.js | v24.19.0 |
| Node.js 아키텍처 | Windows x64 |
| 개발용 Python | 3.12.10 |
| 서버 주소 | http://127.0.0.1:8090 |
| 프론트엔드 | HTML, CSS, JavaScript |
| 백엔드 | Node.js |
| 외부 API | Kakao Local, Kakao Mobility, Kakao Maps |

신규 서비스는 Node.js 기본 모듈을 사용하므로 별도의 npm 패키지 설치가 필요하지 않다.

실시간 경로 추천 서비스 실행에는 Python 가상환경 및 모델 재학습 환경이 필요하지 않다.

Python 환경은 데이터 처리, 모델 학습, 평가 및 공간 타일 재생성에 사용한다.

### 5.2 서비스 실행 방법

1. SafeRoute 실행용 폴더를 준비한다.
2. START_SAFEROUTE.cmd 파일을 실행한다.
3. 서버 시작 메시지를 확인한다.
4. 브라우저에서 SafeRoute 화면을 확인한다.
5. 카카오 REST API 키를 입력한다.
6. 카카오 JavaScript 키를 입력한다.
7. 지도 켜기 버튼을 선택한다.
8. 출발지와 도착지를 검색하고 선택한다.
9. 최대 우회 배율을 선택한다.
10. 경로 탐색을 실행한다.
11. 추천 경로와 상세 지표를 확인한다.

브라우저가 자동으로 열리지 않는 경우 다음 주소에 직접 접속한다.

    http://127.0.0.1:8090

서버 종료는 서버 실행 터미널에서 Ctrl+C를 사용한다.
