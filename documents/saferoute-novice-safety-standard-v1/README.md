# SafeRoute 초보운전자 안전경로 기준 v1

SafeRoute는 가장 빠른 길 대신 **초보 운전자가 실수하기 쉬운 상황과 사고 노출을 줄이는 경로**를 추천합니다. 카카오·네이버·Google·TMAP의 일반 길찾기를 비교 기준으로 사용하고, 공공 도로망과 교통·사고·기상 데이터를 이용해 자체 안전 비용을 계산합니다.

## 1. 제품 원칙

1. 통행금지·도로폐쇄·역주행·차량 제한 위반은 점수와 관계없이 제외합니다.
2. 사고 가능성과 사고 심각도를 가장 크게 반영합니다.
3. 비보호 좌회전, U턴, 급차선 변경, 복잡 교차로처럼 초보자가 어려워하는 조작을 별도 평가합니다.
4. 고속도로 전체를 위험하다고 보지 않고 진입·합류·엇갈림 구간의 부담만 평가합니다.
5. 어린이·노인 보호구역은 무조건 회피하지 않고 운영시간, 보행자 노출, 제한속도를 함께 반영합니다.
6. 정체 자체를 위험으로 단정하지 않고 속도 차이, 급감속 가능성, 차로 변경 부담을 평가합니다.
7. 데이터가 없거나 오래됐으면 안전하다고 가정하지 않고 불확실성 점수를 높입니다.
8. 화면에서는 `안전한 경로` 대신 `추정 위험이 더 낮은 경로`라고 표시합니다.

## 2. 링크 위험점수

도로 링크마다 다음 네 요소를 0~100점으로 계산합니다. 숫자가 높을수록 위험하거나 초보자에게 어렵습니다.

| 요소 | 초기 비중 | 내용 |
|---|---:|---|
| `base_crash_risk` | 50% | LightGBM이 예측한 사고·중상 위험. 과거 사고, 도로 구조, 교통량 등을 사용 |
| `novice_complexity` | 25% | 비보호 좌회전, U턴, 합류, 짧은 구간 차선 변경, 복잡 교차로, 좁은 도로 |
| `dynamic_hazard` | 20% | 현재 사고·공사, 강수, 적설·결빙, 안개, 야간 시야, 급격한 속도 차이 |
| `uncertainty` | 5% | 핵심 데이터 결측, 오래된 교통·기상 정보, 모델 신뢰도 부족 |

```text
link_risk =
    0.50 × base_crash_risk
  + 0.25 × novice_complexity
  + 0.20 × dynamic_hazard
  + 0.05 × uncertainty
```

LightGBM에 실시간 교통·기상 피처까지 직접 넣는 경우에는 같은 요소를 `dynamic_hazard`에서 다시 더하지 않습니다. 중복 가중을 막기 위해 모델 입력과 규칙 점수의 역할을 모델 카드에 기록해야 합니다.

## 3. 초보운전자 조작 부담

다음 값은 학습 전 MVP에서 사용할 초기 패널티입니다. 실제 주행·사고 데이터로 검증한 뒤 조정합니다.

| 상황 | 초기 패널티 | 적용 방식 |
|---|---:|---|
| 비보호 좌회전 | +45초 | 대체 경로가 있으면 강하게 회피 |
| U턴 | +60초 | 필수인 경우에만 허용 |
| 5지 이상 또는 복합 교차로 | +35초 | 통과 1회마다 적용 |
| 고속 합류·진출 | +40초 | 고속도로 본선에는 일괄 적용하지 않음 |
| 회전 직전 250m 이내 차선 변경 | +30초 | 필요한 차선 변경마다 적용 |
| 1km 안에서 3회 이상 연속 차선 변경 | +50초 | 추가 패널티 |
| 다차로 회전교차로 | +30초 | 단일차로 회전교차로는 +10초 |
| 폭이 좁은 생활도로·골목 | +20초/km | 통행 가능 여부 확인 후 적용 |
| 급커브·급경사·시야 불량 | +20초/구간 | 야간·우천 시 가중 확대 |
| 스쿨존·노인보호구역 | +5~20초 | 운영시간·보행 노출에 따라 적용 |

패널티는 해당 도로가 실제로 더 위험하다고 확정하는 통계값이 아니라, 초보 운전자의 조작 부담을 경로 비용으로 표현한 초기 제품 설정입니다.

## 4. 경로 전체 점수

평균만 사용하면 짧은 고위험 구간이 숨겨질 수 있으므로 평균·상위 위험·최대 위험을 같이 사용합니다.

```text
route_risk =
    0.55 × 주행시간 가중 평균 링크위험
  + 0.30 × 링크위험 90백분위
  + 0.15 × 최대 링크위험

route_safety_score = 100 - route_risk
```

| 등급 | 점수 | 사용자 표시 |
|---|---:|---|
| A | 85~100 | 추정 위험 매우 낮음 |
| B | 70~84 | 추정 위험 낮음 |
| C | 55~69 | 주의 구간 있음 |
| D | 0~54 | 고위험 구간 있음 |

등급은 동일한 시점과 지역의 후보 경로끼리 비교하는 용도로 사용합니다. 사고가 발생하지 않는다는 보증으로 표시하면 안 됩니다.

## 5. 추천 경로 선택 규칙

1. 카카오·네이버·Google·TMAP 또는 자체 경로 엔진에서 후보 경로를 만듭니다.
2. 법규 위반과 폐쇄도로가 포함된 후보는 제거합니다.
3. 남은 후보의 모든 도로 링크에 위험점수를 계산합니다.
4. 가장 빠른 경로보다 예상시간 20%, 거리 25%를 초과하는 후보는 기본 초보안전 모드에서 제외합니다.
5. 고위험 노출이 최소 10% 감소하지 않으면 큰 우회를 권하지 않습니다.
6. 위험 차이가 모델 오차 범위보다 작으면 `안전 우위 불확실`로 표시하고 일반 경로를 제공합니다.
7. 선택 이유를 최대 세 개까지 보여줍니다. 예: `비보호 좌회전 2회 감소`, `사고다발구간 1.4km 회피`, `추가시간 6분`.

## 6. 강제 제외 조건

- 통행금지, 도로폐쇄, 공사로 전면 차단된 링크
- 일방통행 반대 방향과 금지된 회전
- 차량 높이·중량·차종 제한 위반
- 침수·산사태·결빙 등 공식 통제 구간
- 연결이 끊겼거나 좌표가 손상된 링크
- 실시간 정보가 임계시간을 넘고 대체 검증도 불가능한 중대 위험 구간

## 7. 출시 전 통과 기준

- 법규·방향·도로 연결 위반 0건
- 일반 추천 경로 대비 고위험 노출 중앙값 10% 이상 감소
- 추가시간 중앙값 10% 이하, 95백분위 20% 이하를 목표로 검증
- 주야간·우천·도시·도로종류별 확률 보정 오류가 허용 범위 안에 있음
- 경로 실패 시 일반 내비 경로로 안전하게 전환
- 실제 적용 전 그림자 모드, 시뮬레이터, 동의받은 제한적 주행 시험 순으로 검증

## 포함 파일

- `safety_scoring.yaml`: 점수식과 패널티 설정
- `feature_schema.csv`: 학습·규칙 피처 정의와 데이터 출처
- `route_profiles.json`: 초보안전·균형·빠른안전 모드 설정
- `reason_codes.json`: 화면에 표시할 선택 이유 코드
- `training_validation.md`: LightGBM 학습 및 검증 기준
- `example_link_scores.csv`: 구현용 예시 형식이며 실제 측정값이 아님

이 문서의 가중치와 임계값은 학습 전 v1 초기값입니다. 실제 사고율, 교통량, 주행시험으로 검증하고 버전별로 변경 이력을 남겨야 합니다.
