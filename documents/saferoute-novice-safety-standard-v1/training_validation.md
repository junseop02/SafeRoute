# LightGBM 학습·검증 기준

## 예측 목표

LightGBM은 완성 경로를 직접 선택하지 않습니다. `도로 링크 × 진행 방향 × 15분 시간대`별 예상 피해량을 예측하고, A* 또는 Dijkstra가 이 값을 도로 비용으로 사용해 경로를 만듭니다.

```text
ExpectedHarm(link, time)
  = P(사고 | 링크, 시각, 당시 이용 가능한 정보)
  × E(사고 심각도 | 사고 발생)
```

초기 심각도 가중치는 물적 피해 1, 경상 5, 중상 20, 사망 100으로 둡니다. 이는 정책 초기값이며 전문가 검토와 실제 데이터 분포로 확정해야 합니다. 교통량이 있으면 차량 100만 대·km당 예상 피해량을 사용합니다. 노출량이 없으면 결과를 절대 사고확률로 부르지 않고 상대 위험 순위로만 사용합니다.

## 권장 모델 구조

- 사고 발생 여부: LightGBM binary objective
- 사고 심각도: 사고 표본만 사용한 별도 multiclass 또는 regression 모델
- 희귀 사고 보정: class weight와 확률 캘리브레이션 사용
- 모델 출력: 검증 기간에서 Platt, Beta, Isotonic 중 안정적인 방법으로 보정
- 도로 ID 자체는 입력하지 않음
- 비보호 좌회전·U턴·연속 차로변경은 설명 가능한 규칙 점수로 분리

한 모델로 예상 피해량을 직접 학습하는 경우 Poisson 또는 Tweedie 목적함수도 비교하되, 교통 노출량과 과산포를 반드시 확인합니다.

## 데이터 누수 방지

1. 무작위 행 분할을 사용하지 않고 과거 학습 → 미래 검증 → 최종 미래 시험 순서로 분할합니다.
2. 읍면동·도로 회랑 전체를 공간 홀드아웃하고 인접 링크가 학습·시험에 섞이지 않도록 완충 구역을 둡니다.
3. 동일 출발–도착 쌍과 80% 이상 겹치는 경로는 같은 fold에 넣습니다.
4. 향후 15분을 예측하면 분할 경계에 최소 15분 embargo를 둡니다.
5. 사고 이후 발생한 정체, 사후 확정 기상, 나중에 수정된 도로정보를 입력하지 않습니다.
6. 사고 이력 집계, 결측치 처리, 스케일링, 캘리브레이션은 각 fold의 학습 자료만으로 계산합니다.
7. 동일 사고의 중복 신고와 인접 링크 복제는 한 사건으로 묶습니다.
8. 지도·도로망·기상·교통 데이터는 당시 서비스 시점에 알 수 있었던 버전을 재현합니다.

## 링크 모델 검증 지표

- PR-AUC
- 중상·사망 사고 가중 Recall
- 위험 상위 10% 링크에서 실제 사고 포착률
- Log loss와 Brier score
- Calibration slope, intercept, ECE와 reliability curve
- 천안/아산, 도심/외곽, 주간/야간, 맑음/우천, 도로종류별 성능

정확도와 ROC-AUC만으로 출시 여부를 결정하지 않습니다. 희귀 사고에서는 모든 링크를 안전으로 예측해도 정확도가 높게 나올 수 있습니다.

## 경로 수준 검증

동일 출발지·도착지·출발시각의 일반 추천 경로와 비교합니다.

- 거리·시간·교통량으로 보정한 예상 피해량
- 고위험 링크 통과 거리와 시간
- 경로 중 최대 위험과 상위 5~10% 구간 위험
- 비보호 좌회전, U턴, 합류, 복잡 교차로, 급차선 변경 횟수
- 추가 소요시간과 추가거리
- 경로 생성 성공률과 법규·방향 위반 건수
- 동의 기반 시험에서 급제동, 급차로변경, 경로이탈 빈도

핵심 결과는 `위험 감소율–추가시간` Pareto 곡선으로 제시합니다. 모델이 계산한 위험점수로 같은 모델을 최종 평가하지 않고, 완전히 분리된 미래 사고자료나 동의받은 주행자료를 사용합니다.

## 초기 출시 게이트

| 항목 | 초기 목표 |
|---|---:|
| 법규·그래프 오류 | 0건 |
| 고위험 노출 감소 | 중앙값 10% 이상 |
| 추가시간 | 중앙값 10% 이하 |
| 추가시간 95백분위 | 20% 이하 |
| 안전 후보 신뢰도 | 위험 상한이 비교 경로 위험 하한보다 낮음 |
| 핵심 피처 결측률 | 20% 이하 |

기준을 통과하지 못하면 일반 길찾기 경로를 제공하고 `안전 우위 불확실` 또는 `데이터 부족`을 표시합니다.

## 배포 순서

1. 과거 데이터 백테스트
2. 실제 사용자에게 보이지 않는 그림자 모드
3. 시뮬레이터·전문 검토
4. 동의받은 제한적 주행 시험
5. 천안·아산 일부 구역 단계 배포
6. 월별 캘리브레이션·입력 분포·성능 드리프트 감시

모델 버전, 학습기간, 피처 목록, 데이터 출처, 임계값, 알려진 한계를 모델 카드로 남깁니다.
