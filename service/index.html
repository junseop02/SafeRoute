추천 경로

경로 추천 점수는 높을수록 P01 정책에서 우선하는 경로입니다. 실제 사고 확률이나 측정된 운전 난이도는 아닙니다.

추천 기준

T09 · 전국 도로 기반 LightGBM 모델
차로 수, 제한속도, 도로 등급, 도로 길이, 분기 수, 주변 교차로 후보 수, 도로 주변 200m 교차로 노드 수를 입력받아 과거 사고다발지역 포함 여부에 대한 모델 점수를 산출합니다.

P01-v1.1 · 경로 추천 정책
매칭 길이로 가중 평균한 T09 모델 점수 80%, 좁은 도로 부담 10%, 교차로 부담 10%를 결합합니다. 경로 추천 점수는 100점에서 종합 부담 점수를 뺀 값이며, 높을수록 P01 정책에서 우선하는 경로입니다.

추천 조건
최단 후보 거리 기준 우회 허용 범위 안에서 도로 매칭률이 80% 이상이고 점수 계산이 가능한 서로 다른 비교 가능 경로가 두 개 이상일 때 추천합니다. 가능하면 세 개 이상의 경로를 탐색합니다. 부담 점수가 같으면 이동 거리, 소요 시간, 경로 ID 순으로 비교합니다. 조건을 충족하지 못하면 가능한 후보만 표시합니다.

모델의 한계
과거 사고다발지역 자료와 전국 도로망을 이용한 상대적 경로 비교 지표입니다. 실제 사고 확률이나 초보 운전자의 측정된 운전 난이도를 의미하지 않습니다. 사고 자료에 포함되지 않은 도로가 안전하다는 의미도 아닙니다. P01 가중치는 학습된 값이 아닌 추천 정책의 설정값입니다. 사고다발지 150m 이내 길이 비중은 참고용이며 P01 점수 계산에는 직접 사용하지 않습니다.
